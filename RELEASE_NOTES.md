# Scaffolder 0.9.0-beta.1

Scaffolder `0.9.0-beta.1` is the first public beta release.

It provides a web-based workflow for selecting a frontend stack, previewing
the generated project structure, and downloading the result as a ZIP archive.
This release also establishes the project's support, compatibility, security,
and versioning policies.

## Highlights

- Generate React, Vue, and Next.js projects.
- Configure routing, styling, linting, state management, and additional npm
  dependencies.
- Preview the generated file tree before downloading.
- Use React Router component or data-router modes.
- Use Vue Router and Next.js App Router or Pages Router.
- Apply Tailwind CSS integrations for the primary supported frameworks.
- Use the interface in English or Russian with automatic locale detection.
- Run the service through Docker Compose with health checks and CI/CD.
- Maintain base templates through a pinned Git submodule.

## Support status

This release is a beta, not a stable `1.0.0` release.

The supported core consists of the documented React, Vue, and Next.js
combinations. Additional framework templates and several feature integrations
remain experimental.

See:

- [Supported combinations](SUPPORTED_COMBINATIONS.md)
- [Template compatibility policy](TEMPLATE_COMPATIBILITY.md)
- [Versioning and migration policy](VERSIONING.md)

## Known limitations

- Package-manager selection does not yet guarantee manager-specific lockfiles.
- State-management presets may add dependencies without generating a complete
  store or provider integration.
- Biome and no-linter modes may leave configuration inherited from a base
  template.
- The complete generated-project matrix is not yet installed and built in CI.
- Experimental framework templates have less feature-specific patch coverage.

## Upgrade and migration notes

This is the first published release, so there is no previous release to
migrate from.

Projects generated by this beta are independent projects and are not
automatically upgraded by later Scaffolder releases.

## Verification

Before publishing this release, run:

```bash
pre-commit run --all-files --show-diff-on-failure
cargo test --manifest-path apps/api/api/Cargo.toml --locked
pnpm run build:web
```

The template submodule commit referenced by the release must be available in
the remote `Teamofeyy/templates` repository.
